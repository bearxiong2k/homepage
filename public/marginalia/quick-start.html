Marginalia Quick Start

Marginalia is a browser-local reading workspace for PDFs and HTML documents. This page is meant to be marked up while you read it, so you can learn the basic features before importing your own material.

Start with a few practice marks here, then import your own source when the basic flow feels familiar.

Start by Marking Up This Page

Because you selected Start with quick-start.html, this guide has been imported as the first source in your current library. Treat it as a practice document.

Marginalia keeps the source document on the left and your notes in the margin. Highlights, Markdown text, pictures, quick marks, and ink drawings are stored separately from the original source.

Practice sentence: Select this sentence, choose H&N, and write a short note about what you expect Marginalia to help you remember.

Try the Core Features

  1. Create a note from text. Select the practice sentence above, then choose H&N (highlight with note) in the selection pop-up. A highlighted note should appear in the side panel. Choose the circular H when you want the highlight only. Click a highlight-only mark later and choose the gray R to remove it.
  2. Create a blank margin note. Double-click empty space in the side panel, or press Alt+N to place one at the current reading position. This creates a note even when you do not want to attach it to selected text.
  3. Edit a margin note. Click a plain-text body and type, or use Edit on rendered Markdown. Markdown, LaTeX math such as $x^2$, and fenced mermaid diagrams stay read-only after you choose Render.
  4. Try a quick mark. Drag the binder-clip button from the left rail onto a paragraph, or press Alt+M to mark the current reading position. Use this for fast marks while reading.
  5. Try drawing or adding a picture. Pin a note, then use an Add here row to insert Text, Draw, or Picture above, between, or below its blocks.
  6. Save once. After making a few practice marks, use Save. Saving creates a portable library package outside the browser.

The left rail is intentionally compact. I imports another source or package, S saves the current source or library, and L opens the library view.

Note Buttons

Each margin note has a small button row. The available buttons depend on the source and whether the note has a highlight.

  • ▲Collapse. Hide the note body. The button changes to ▼ when the note is collapsed.
  • FFocus mode. For HTML sources, focus on the selected note and its highlighted passage.
  • +Add highlight. Attach another selected passage to the same note.
  • −Remove highlight. Click a highlight attached to the note to remove that highlight.
  • 「」Pin editor. Open a larger note editor. Its boundary rows add Text, Draw, or Picture blocks at any position, and each existing block has its own Remove control.
  • ×Delete. Remove the note after confirmation.

Create notes by selecting text and highlighting it, by double-clicking blank space in the side panel, or from the keyboard with Alt+N. Use Alt+M for a quick mark at the current reading position.

Reading and Layout Controls

R Pure reading mode. Use this when you want the source to take over the screen. It hides the note margin and editing controls so you can read with fewer distractions.

Draggable separator. Drag the vertical separator between the source and notes to give more width to the text or more width to the margin.

Import and Save Behavior

Use I to import a PDF, HTML file, single-source bundle, or library package. If a library is already open, importing a PDF or HTML file adds it to the current library.

Importing a saved library package opens that package as the current library. If another library is already open, Marginalia asks before replacing the current browser-local library context.

Use S to save. When a library is open, Save writes the whole library: all sources, highlights, note text, quick marks, and ink drawings. If you are working with only one source outside a library, Save offers a single bundle or a new library package.

PDF is the right choice for papers, scans, books, or forms. HTML is the right choice for prepared web pages or exported reading files.

Marginalia does not write highlights or notes back into your original PDF or HTML file. Your source file remains where it was on your computer, unchanged.

Using a Graphic Tablet

Marginalia works with a trackpad or mouse, but freehand notes are best with a graphic tablet. A pen tablet gives better control for arrows, diagrams, symbols, and handwritten margin notes.

Set Up the Tablet

  • Connect the tablet before opening your reading session. If your tablet maker provides a driver, install or update it first.
  • In the tablet settings, map the pen to the screen area where your browser appears. If the pointer feels offset, recalibrate or remap the tablet area.
  • Keep pressure sensitivity enabled if your tablet supports it. In Marginalia's ink toolbar, leave Pressure checked for natural line weight.

Draw in Marginalia

  1. Create or open a margin note.
  2. Use Draw in the appropriate Add here row to insert an ink canvas.
  3. Use Pen, Eraser, Color, Width, and Pressure in the ink toolbar.
  4. If you need more room, drag the small handle at the bottom of the drawing area to make it taller.

Tablet tip: use short strokes for diagrams and corrections. Short strokes are easier to erase, undo, and redraw than one long continuous line.

Where Your Data Is Stored

Marginalia has two storage layers: a working copy in the browser, and saved library packages that you create on your computer.

Working copy

While you read, Marginalia stores a copy of each imported source, annotation metadata, Markdown note bodies, note pictures, quick marks, and ink strokes in this browser's IndexedDB storage for this exact site address.

That working copy belongs to this browser profile on this computer. It is not automatically available in another browser, another profile, or another computer.

Saved package

When you use Save, Marginalia writes a portable library package. Depending on your browser, this may be a folder you choose, usually ending in .annotator-library, or a downloaded zip file ending in .annotator-library.zip.

If the browser downloads a zip, it usually goes to your Downloads folder unless your browser asks you to choose a location.

To continue later, return to this site and import the saved library package. The package is what carries your sources, highlights, note text, quick marks, and drawings together.

Good habit: save after an important reading session and keep the package somewhere you back up, such as iCloud Drive, Dropbox, Google Drive, or an external drive.

Important: if you clear this site's browser data, use private browsing, reset the browser profile, or move to another computer without saving a package, the browser working copy may be gone.

Privacy and Original Files

The hosted PWA is designed for visitors. You do not need an account for browser-local reading and annotation.

Your original PDF or HTML file is not edited by Marginalia. Saved library packages contain their own copy of the source plus your annotations, so treat saved packages as personal reading data.

On a shared computer, save your library package to your own folder, then clear this site's browser data when you are done if you do not want the working copy left in that browser profile.
